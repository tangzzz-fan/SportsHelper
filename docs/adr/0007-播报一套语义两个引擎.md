# 播报：一套语义，两个引擎

**Status:** accepted（2026-10-25）

审计先定了性：文案层与闸门层的分层是对的（`DongKeCore` 不 import AVFoundation，61 条单测），但「什么时候说、一拍说几句、说不下怎么办」没有模型。结果休息归零在同一个 tick 连发两句，实测 8.79 秒；同一份代码，主线程晚 60ms 就变成第一句被切在 0.11 秒。**在换引擎之前必须先有话句语义**，否则神经引擎 100–800ms 的合成延迟会把同一个缺陷放大成「所有指令排队堆积」。

## 决定

1. **一拍一句。** 休息归零不再「先报休息结束、再报下一组」，合并成一句「俯卧撑，第 3 组，共 3 组，12 次」。省 4.2 秒，信息不重复。只有没有下一组时才念「休息结束」。
2. **预算按秒，不按字。** 单句 ≤4 秒（实测 4.0–4.3 字/秒；组开始最短也要 3.8 秒，3 秒做不到）。超了先丢「共 N 组」，再丢预告；动作名与剂量最后才动。删掉 `textLimit = 40`——换算过来是 10 秒，等于没有上限。实现落在 `WorkoutAnnouncement` 的 `*Budget`，超预算先丢「共 N 组」。
3. **触发面收窄。** 动作中只留两类：中段一句要点、最后 3 秒倒数。删「时间到」的语音（计时归零已由系统音 + 触觉表达，再念是四声重复）；删「加油」（`allowsEncouragement` 从未被置 true，是死代码，且语气与「给出口」的产品立场不符）。
4. **端口从「喇叭」改成「话句」。** 现有 `SpeechAnnouncing` 只有 `isSpeaking / speak(String) / stop()`，没有句柄、没有事件、没有可用性、没有音色档案、没有线程模型。神经引擎需要的这五样它都装不下。新端口 `SpeechRendering` 带 `SpeechRequest`（id / priority）、`SpeechOutputEvent`（started / finished / cancelled / failed）、`SpeechAvailability`、`SpeechProfile`。**不做 deadline**：既然一拍一句、不排队，过期就没有作用面；要停靠 scenePhase。
5. **会话只有一个 owner。** 播报与收音现在各自对 `AVAudioSession.sharedInstance()` 调 `setActive(true/false)`，靠「两个功能不同屏」维持正确。收进 `AudioSessionArbiter`，引用计数。
6. **音色先于引擎。** 现有代码只传 `language: "zh-CN"`，拿到的是系统默认音色；本机实测返回 compact Tingting，而同一台机器装着 premium 的「声音2」。先按 `quality` 选已安装的最高档，并在设置页显示当前音色名。
7. **换引擎要三条同时成立**：商用许可干净、iPhone 上 RTF < 0.5、体积可接受（随包或按需下载）。缺一条不做。

## Considered options

- **只调 rate / 加停顿标点。** 零成本，但改不了音色，也解决不了 8.79 秒。
- **Kokoro-82M。** 音质好、权重 Apache-2.0，但中文在 iPad 上 RTF 1.5–1.8（比实时慢），中文 G2P 依赖 eSpeak-NG（GPL-3.0）——闭源上架是许可毒丸。
- **Matcha-icefall-zh-baker。** 速度快、体积小，但训练语料 DataBaker 明确「仅限非商用」，sherpa-onnx 文档自己挂了 Caution。
- **vits-icefall-zh-aishell3。** Apache-2.0、29MB、RTF 0.16，许可与性能都干净，但 8kHz 窄带——音质低于系统 premium 音色，换了不赚。
- **MeloTTS zh_en（sherpa-onnx）。** MIT、44.1kHz、163MB，是唯一「许可干净 + 音质高于系统 compact」的候选，但 RTF 在树莓派上 2.5，必须先在 iPhone 上实测首音延迟。
- **随包 vs 按需下载。** 随包 +160MB 伤安装转化；按需下载要多一套进度 / 失败 / 回退，但保住「打开就开始」，且换音色不用发版。选按需。

## Consequences

- Core 新增 `SpeechRequest` / `SpeechOutputEvent` / `SpeechRendering`，删除 `isSpeaking` 轮询；App 新增 `SystemSpeechRenderer`、`SpeechRouter`、`AudioSessionArbiter`，`SystemSpeechAnnouncer` 退化成纯适配器。
- 测试口径从「送了什么文本」升级为「一拍最多一句 + 每句 ≤3 秒 + 过期不念」。出声层仍然只能靠真机，这条缺口写在明处。
- `WorkoutVoiceSessionTests` 里「后一句由引擎打断前一句」的用例名与真实行为相反（实测同 tick 是排队），随端口重画一起改写。
- 神经引擎进 1.x 的前置是 `06-神经引擎试点` 的三条门槛；未过则永久停在「系统音色最高档」，这不是失败，是结论。
- 与 ADR-0001（不用 AI 也要能开始）一致：音色是增强项，模型缺失时系统 TTS 永远可用。
