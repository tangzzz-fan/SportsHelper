# 套路不复用计划模型

**Status:** accepted（2026-10-25）

五禽戏、八段锦是连续段序列，没有「组」、没有休息日、没有周排期。决定新增 `Routine`（段序列：名称 / 时长 / 口令）与一个独立播放页，不复用 `PlanDay`。

**Considered options**：塞进计划当「一天」，每个动作 1 组按秒计。省一周代码，但要在播报、总结、历史、通知排程四处加分支去假装它不是训练；且 10 式全进打卡记录后，「完成率」被迫回答「五禽戏算不算一次训练」——这正是上一轮把统计口径弄脏的同一个坑。

**Consequences**：多一条执行管线，约 1–1.5 周。段序列的每一式仍然是一条 `ExerciseEntry`，所以图示、动作分步、别名解析全部复用现有机制，只是 `purposes` 不含 `.strength`，进不了力量池。
