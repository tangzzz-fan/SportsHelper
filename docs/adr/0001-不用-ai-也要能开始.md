# 产品边界：不用 AI 也要能开始

**Status:** accepted（2026-10-25）

原定位要求用户先有一份 AI 计划（去 ChatGPT 要，或粘贴进来）。这条漏斗对老年用户是断的——他们不会去要一份计划。决定保留「执行」为核心不动，但增加一条零输入路径：内置 4 周入门计划 + 套路内容（五禽戏、八段锦），并把「适老」落成一个**大字模式开关**（同一套内容的另一种呈现），而不是第二套产品。

**Considered options**：① 只做无障碍，不动产品模型——解决不了「不会开始」这个真正的断点；② 重开「视频教学 / 课程库」——欠永久内容债，且要推翻冻结项。「不做视频」这条边界保留，套路用线稿 + 步骤 + 语音。

**Consequences**：内容第一次成为长期成本（此前内容只是 47 条动作的要点）；「不做课程库」这条非目标被部分重开，重开范围只到「内置内容包」，不含视频、不含用户自建课程、不含排期。
