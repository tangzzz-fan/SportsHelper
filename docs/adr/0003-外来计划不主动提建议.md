# 外来计划不主动提建议

**Status:** accepted（2026-10-25）· 范围由 ADR-0004 收窄

ADR-0004 定下「计划只因用户选择而变」之后，自有与外来计划不再是「能不能自动改」的区别——都不能。剩下的区别是**提不主动提**：`source` 为 `generated` / `manual` 的**自有计划**，提案在计划页主动出现，一周一次；`ai` / `pasteJSON` / `pasteText` 的**外来计划**，提案不主动出现，只在用户进入「调整」入口时给一条。

理由是 `PlanOriginNotice` 已经在告诉用户「这份 AI 计划可能写错，别照单全收」。同一个来源，一边提醒用户别信、一边主动劝他改，两句话不能同时成立——**你不能既说「我不敢保证它对」，又说「但我知道该怎么改它」。**

**Considered options**：① 统一主动提。实现最省，但粘进来可能是教练或医生排的，App 不知道背后的意图（比如故意压低三周做恢复）；主动提议等于替第三方改方案。② 统一不主动提。自有计划的渐进就永远不会发生——用户不会主动去问「我是不是该加量了」，而这恰恰是渐进最需要被代劳的那一步：看见。

**Consequences**：`PlanSource` 从「徽章」升级成「提案策略」的输入，但**不是**「改写权」的开关。提案一次只给一条，不攒成清单——清单等于让用户替 App 排序，那正是分权的意义所在。`PlanAdjustView` 的文案要收缩：它现在承诺「太难或太占时间就在这儿改」，而这两件事是提案该做的事；留着会让用户以为必须自己发现该减量。
