# 个体化只调变量，不调目标

**Status:** accepted（2026-10-25）

剂量回路的另一半是「App 越来越懂用户」。把这件事按运动科学的 **individualization**（个体化）理解，不按 **personalization**（个性化）理解：同一条训练原则、同一个目标，**变量值**因人而异，而不是内容因人而异。

三层分工固定下来：**能力**决定剂量（做多少），**耐受**决定节奏（多快加），**偏好**只决定**动作选择**（走哪条路）。**偏好不进剂量公式**。理由是偏好一旦进公式就退化成迎合：用户总跳过深蹲 → 系统把腿的量分给别的动作 → 腿的训练量下降 → 八周后没效果，而用户以为自己「被理解了」。正确的处理是同一个目标换一条路：深蹲 → 保加利亚分腿蹲，主肌群不变，剂量一点不减。

**Considered options**：① 偏好直接调剂量。用户即时满意度最高，但训练效果下降，而且下降是延迟的、不可归因的——这正是这一整轮要消灭的那类错误：做了别的还不说。② 完全无视偏好。用户会一直跳过同一个动作，而 `tooHard` 与 `noEquipment` 这两个原因本来就在说「这个动作不适合我」；无视它等于让计划慢性失效。③ 偏好只改路径。需要一个判据说明「换到哪个动作算同一条路」——用 `primaryMuscles` 有交集，不需要动作等价类。

**Consequences**：`primaryMuscles` 从「算剂量」升级成「换路径」的唯一依据。等价的定义是主肌群有交集，不是动作模式相同——这会带来误判（深蹲与腿举主肌群相同、模式不同），可接受，因为误判的代价只是「换了个不太理想的替代」，而不是剂量算错。

另外，判断「App 是否更懂我」的唯一可证伪判据是**预测误差在缩小**：周一预测的每组次数与周末实际完成之差，逐周收窄才叫懂；不收窄说明它只是在套规则。这条要求**从票 02 起就把 `plannedValue` 与 `actualValue` 配对落库**，而不是只记完成与否——只记完成，误差永远是 0，也就永远证明不了任何事。
