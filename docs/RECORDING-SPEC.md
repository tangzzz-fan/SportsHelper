# 播报音条录制规范

> 给配音老师的工作单。配套清单：`docs/recording-script.csv`（496 条）。
> 一句话背景：这些音条会在训练中被**逐段拼起来**播报，不是整段播放。

## 0. 先理解这些音条怎么用

一节课里听到的完整一句话，是由 3–5 个音条拼出来的。以「俯卧撑，第 1 组，共 3 组，10 次」为例：

| 音条 | 播报原文 | 在句子里的位置 |
|---|---|---|
| 1 | 俯卧撑 | 开头，后面还有话 |
| 2 | 第 1 组 | 中间 |
| 3 | 共 3 组 | 中间 |
| 4 | 10 次 | **收尾** |

程序会在段与段之间插 **70 毫秒**静音，然后连续播放。

**所以录制方式和录广告、录有声书都不一样**：

- 前面几段**不要做完整的收尾降调**——一降调，拼起来就像在念清单
- 每段都要有「后面还有」的感觉，气不要断干净
- 只有明确标了「收尾」的那一类（`完成率 N%`）可以落下来

这是整份工作单最重要的一条。录 10 条试听、双方确认感觉之后，再往下录。

## 1. 交付格式

| 项 | 要求 |
|---|---|
| 文件格式 | WAV（不要 mp3、不要 m4a） |
| 采样率 | **48000 Hz**（我们统一重采样到 22050，源头给高的更保险） |
| 位深 | **24 bit**（16 bit 也可以接受） |
| 声道 | **单声道**（不要立体声） |
| 电平 | 峰值 **−6 dBFS** 左右，**任何一条都不许削顶（爆音）** |
| 文件名 | 严格按清单里的「文件名」列，例如 `001_2898d62e689a5a25.wav` |
| 目录 | 一个目录平铺，不要建子文件夹 |

文件名里那串 16 位十六进制是程序查表用的，**不能改、不能漏**。序号只是为了方便你我核对。

## 2. 录音环境

- **安静**：关空调、关风扇、关窗。手机静音放远。
- **不要空房间**：光秃秃的墙会有回音（听起来像在浴室）。有衣柜、书架、地毯、窗帘的房间最好。没有的话在身后挂条毯子。
- **不要在卧室床上录**：贴身吸音会让声音发闷。
- 连续录 40 分钟休息 10 分钟，嗓子累了音色会变，这条对一致性影响很大。

## 3. 麦克风与摆位

| 项 | 建议 |
|---|---|
| 麦克风 | USB 电容麦（如 AT2020、NT-USB）或动圈麦（如 SM58）都可以；**不要用耳机线麦、不要用手机** |
| 距离 | 嘴到麦 **15–20 cm**，略微偏轴（不对着鼻子吹气） |
| 防喷罩 | 有就装，没有就把麦稍微转偏 15 度 |
| 支架 | 用支架，不要手持（手持会有低频抖动噪声） |

**全程不要动麦克风位置、不要改增益。** 中途调了，前后音量就对不上。

## 4. 语气

整体定位：**一个在健身房带课的教练，就在学员旁边说话**。不是广播、不是广告、不是 AI 助手。

| 组 | 内容举例 | 要求 |
|---|---|---|
| 固定短语 | 开始训练 / 休息 / 休息结束 / 接下来 | 见清单里的逐条提示。`开始训练`要有启动感，`休息`把气放下来 |
| 动作名 | 俯卧撑 / 哑铃划船 | 念清楚、不拖长。**后面还跟着组数，句尾别下坠** |
| 组数与进度 | 第 3 组 / 共 12 组 / 完成 9 组 | 数字干脆，像报数 |
| 次数 | 10 次 / 每侧 12 次 | 干脆，短促 |
| 时长 | 40 秒 / 2 分 / 5 分钟 | 注意**「分」和「分钟」是两个不同的词**，别念混 |
| 距离 | 30 米 / 5 公里 | 干脆 |
| 完成率 | 完成率 100% | 结束时念，可以带一点收尾的满意感 |
| 动作数量 | 3 个动作 | 一口气带过，中间不顿 |
| 单个数字 | 0–10 | 只念字面，不拖 |
| 动作要点 | 「收紧臀部把髋顶到躯干成一条线，别用腰反弓」 | 像教练在旁边提醒，稍慢但不要拖，句尾同样别下坠 |

**语速**：清单里有「参考时长」列，是现有机器播报的时长。**不要刻意去对齐秒数**——按自然语速念，落在参考值 ±20% 就可以。刻意凑时间会让语气变僵。

## 5. 录制方法

1. **一条一个文件，一条只念一遍。** 念错了**整条重来**，不要剪掉半句拼接——剪接处会有气息断层，拼进整句里很明显。
2. 每条前面留 0.3–0.5 秒静音，后面留 0.5 秒。方便我们切。
3. **同一条文本连念 3 遍**（三个片段，我们挑最好的一条）是允许且推荐的，能省掉大量来回。这种情况下文件名加后缀 `_a` `_b` `_c`，例如 `001_2898d62e689a5a25_a.wav`。
4. 不要连读。即使清单里「第 1 组、第 2 组、第 3 组」排在一起，也**每条单独起头**，不要像念数一样连成一串。
5. 每录完 50 条左右回听一遍，发现音色变了（嗓子紧了、位置跑了）就停下来休息。

## 6. 建议的分批

不要一次录完 496 条。分三批，每批录完先发来听：

| 批次 | 内容 | 条数 | 目的 |
|---|---|---|---|
| 第 1 批 | 固定短语 4 条 + 动作名前 10 条 + 组数前 10 条 | **24** | 定语气、定音色。**这批我们确认后再往下** |
| 第 2 批 | 组数剩余 86 + 次数 50 + 时长 44 + 距离 50 + 完成率 21 + 动作数量 20 + 单个数字 11 | **282** | 数字类，量大但简单 |
| 第 3 批 | 动作名剩余 40 + 全部动作要点 150 | **190** | 最长的一组，需要状态好时录 |

合计 24 + 282 + 190 = 496。

## 7. 验收标准

我们收到后会做这几项检查，任一条不过会退回重录：

1. **格式**：48 kHz / 24 bit / 单声道 / WAV
2. **无爆音**：峰值不超过 −3 dBFS，没有削顶
3. **无底噪**：静音段没有明显电流声、空调声、键盘声
4. **无口误**：逐条对照原文。数字念错（「第 3 组」念成「第 4 组」）是最常见的退回原因
5. **音色一致**：整批的基频和亮度落在同一区间（我们会用工具量，不在同一区间会退）
6. **片段感**：抽查拼成整句后，段与段之间不像在念清单
