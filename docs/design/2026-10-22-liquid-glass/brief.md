# 出稿 brief · 动刻 v2 · Liquid Glass

日期：2026-10-22
取代：`dongke-ios-three-screens.html`（v1，扁平、无玻璃，用户判定不合格）
驱动 skill：`swiftui-design` + `apple-hig`

## 为什么重做

v1 的问题不是丑，是**没有材质**：灰底 + 纯白不透明卡片 + 大阴影，那是 2019 年的平板设计。
用户要求 iOS 26/27 的玻璃质感（Liquid Glass），且玻璃必须是主角。

## 玻璃的硬要求（缺一条就算不合格）

1. **玻璃下面必须有内容。** 玻璃靠折射背景出效果；背景是纯灰时玻璃就等于白色卡片。
   每屏底层先铺内容层（放大的骨架图 / 进度环 / 单色 tint 晕），玻璃浮层压在它上面。
2. **四件套齐**：`backdrop-filter: blur(20~30px) saturate(180%)` + 白色半透明填充（8%~18%）
   + 1px 内高光（`inset 0 1px 0 rgba(255,255,255,.55)`）+ 0.5px 外描边（`rgba(255,255,255,.25)`）。
3. **镜面高光**：120° 的白色 linear-gradient（0 → .14 → 0）斜切，只落在玻璃表面，不落内容。
4. **厚度感**：顶部亮边 + 底部暗边各 1.5px，模拟玻璃切片边缘。
5. **同心圆角**：外层 32–40，内层 = 外层 − 内边距。禁止内外同值。

## 禁止清单（v1 犯过的错）

- 灰底 + 纯白不透明卡片
- 玻璃层下面空无一物
- 用 `box-shadow` 冒充玻璃
- 玻璃上再叠一条不透明白色标题栏

## 冻结口径（不得改动）

- tint 深青绿 `#0E7C66`（深色 `#34B39A`），只用于选中态 / 进度 / 主按钮；每屏 accent ≤2 处
- 字体零打包：只用 `-apple-system` / PingFang SC；倒计时 `tabular-nums`；全项目唯一自定字号 88px
- 间距只取 4/8/12/16/24/32；触控目标 ≥44
- 图标 SF Symbols 风格线性 SVG，`currentColor`，stroke 1.8，无 emoji
- 禁止紫→粉渐变、彩虹渐变、装饰性光斑；背景晕只能用 tint 单色，透明度 ≤12%
