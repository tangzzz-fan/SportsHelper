常见问题

粘进去的计划拆不出来 / 动作名认错了

先把原文按「一天一段」整理一下，再去掉表格线。动刻靠动作名词表匹配，遇到生造的名字（「地狱推举」「燃脂三连」）会认不出来。

三条退路，按顺序试：

  • 在校对页逐条改动作名，改完照样保存——校对页永远可以手工改
  • 把计划改写成 JSON 再粘：字段对不上的地方会逐条标出来
  • 干脆不用这份计划：在计划页按目标、器械、天数、时长让 app 自己排一周
点「用 AI 生成」没反应或报错

先确认网络能通。内置通道是有额度的，额度用完会失败——这时可以到「设置 → AI 直连」填自己的 OpenAI 兼容接口与 Key，保存后重试。

换了自己的接口仍失败，多数是地址少了 /v1，或者 Key 没有该模型的权限。

AI 只是三种入口之一。它挂了不影响已有的计划、训练和记录；要新计划，也可以在计划页用「调整」按新条件本地重排一份。

训练时没有语音播报

按这个顺序查：设置里的「语音提示」是否打开；手机侧边静音开关（静音下播报会走扬声器，但音量可能很低）；媒体音量是否被调到 0；是否连着蓝牙耳机。

语音是按整节课排的，中途切到别的 app 再回来，会从当前这一组继续。

收不到训练提醒

三条一起看：iOS 设置里动刻的通知权限；app 设置里「训练提醒」是否打开；设置页显示的「已排程提醒」是不是 0 条。改过计划之后提醒会重排，稍等一下再看条数。

专注模式或睡眠模式下，提醒可能被静音。动刻用的是本地通知，没有服务器补发，错过就是错过。

换手机了，数据能同步吗

不能。动刻没有账号，也没有云端。换机、卸载、抹掉设备都会让数据消失。如果你用 iCloud 备份整机，恢复到新设备时 app 数据会跟着回来；单独重装 app 不会。

怎么彻底删除我的数据

「设置 → 清空全部数据」会删掉训练记录、计划、档案、自定义动作、API Key 和提醒排程，无法恢复。卸载 app 同样会清除全部数据。我们没有云端副本。

某个动作做不动怎么办

训练页有「这组做不动」——它只降这一组，不算失败，也不会把今天的完成率打成零。也可以选降阶：换成同一动作更轻的做法（比如深蹲换靠墙静蹲）。完全做不了就跳过，并选一个原因（没时间 / 太难 / 疼 / 没器械 / 其他），记录页会统计你都在哪儿卡住。

能离线用吗

能。本地生成计划、训练引导、语音播报、记录统计全部离线。只有「用 AI 生成」和「语音转文字」需要网络（语音优先在本机识别）。

为什么我的完成率不是 100%

完成率的分母是计划内的组数。跳过的组不算完成，临时加练的组不进分母——加组只计入剂量。降阶也计为完成，但会单独出现在降阶率里，所以完成率 100% 不代表每组都按原样做完，三个数要一起看。

支持哪些设备

iPhone，iOS 18 及以上，竖屏。没有 iPad 原生版，在 iPad 上以兼容模式运行。
