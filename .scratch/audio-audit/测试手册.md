## 1. 先开日志（建议，2 分钟）

打开 **Console.app**（`open -a Console`）→ 左栏选中 **Tango** → 右上搜索框输入 `app.dongke.ios`。
看不到内容时，菜单 **Action → Include Info Messages** 勾上。

启动 App 后头两行应该是：

```
[app.dongke.ios:voice] voice pick: <音色名> quality=<1|2|3> candidates=<所有中文音色>
[app.dongke.ios:voice] launch voice=<音色名> enhanced=<true|false> enabled=<true|false> build=<n>
```

`quality`：1 = 默认，2 = 增强，3 = 高级。**模拟器上只有 `Tingting quality=1`**（模拟器不带增强音色），真机应该 ≥2。

后面会出现的行：`policy ...`、`speak prio=... chars=... text=...`、`done seconds=... rate=...`、`cancel`、`interrupted`、`activate playback`、`deactivate`。

模拟器上看同一份日志：

```bash

  log stream --level debug --predicate 'subsystem == "app.dongke.ios"'
```

## 2. 用例

按顺序做，前面几条几分钟就完。

### T0 档位与试听（前置）

今日 → 右上角齿轮 → **语音提示** 选「标准」→ 点 **试听**。

三档的差别（2026-10-25 新加）：
| 档位 | 会听到 |
|---|---|
| 静音 | 什么都不说 |
| 精简 | 开场、每组做什么多少、结束。休息与倒数**不响** |
| 标准 | 再加「休息，60 秒」、倒数 3/2/1、首组的动作要点 |

- 期望：念「开始训练，上肢与核心，3 个动作，共 9 组」。
- 日志：`policy enabled=true ... allows=true` → `speak chars≈20` → `done seconds≈4`。
- 失败长相：点了没声，日志里连 `speak` 都没有 → 策略或开关问题；有 `speak` 没 `done` → 引擎问题。

### T1 音色（票 04）★

看语音卡片第二行，以及日志 `voice pick` 的 `quality`。

| 情况 | 结论 | 动作 |
|---|---|---|
| 显示「增强音色」，quality ≥ 2 | 通过 | — |
| 显示「默认音色 · …」 | 设备上没装增强音色 | 设置 → 辅助功能 → 朗读内容 → 声音 → 中文（中国大陆）→ 下载「声音2」/「婷婷（增强）」；**下载后要杀掉 App 重开**（音色选择有缓存） |

另外：候选列表里会出现 Eddy / Grandma / Grandpa / Rocko 这些趣味音色（机型或系统语言不同，它们也会挂在 `zh-CN` 下）。旧选择器只比 quality，理论上可能挑到一个「老奶奶」音色来念组数。**已改成排除 `isNoveltyVoice`**，日志里的 `candidates` 现在只剩标准音色。

顺带回答一个旧疑问：之前"僵硬"有一部分就是这里——旧代码只按语言取，拿到的是 compact Tingting。

### T2 一拍一句（票 01）★★ 最关键

今日 → 开始训练 → 做完第一组 → 休息 → 等倒计时归零。

- 期望：归零后**只听到一句**「俯卧撑，第 2 组，共 3 组，10 次」。
- 不允许：先「休息结束」再一句同样的话（那是回退了）；也不允许半句被切断。
- 日志判据：两条 `speak` 之间必须是 `done`，不能是 `cancel`。

**另外两件事，2026-10-25 修掉后要一起看：**

1. **点「开始训练」后不再有开场句。** 第一拍就是一组时，只念「深蹲，第 1 组，共 4 组，12 次」。以前会先念「开始训练，下肢力量」，同一瞬间就被下一句截断，只听到「开始训练，下……」——那是 bug，不是特性。休息日（第一步没有组）仍然念开场。
2. **同一节课只会念一次开场。** 视图重建（转场、切后台回来）以前会重建播报会话、把开场重念一遍。日志里 `policy` 出现几次都正常，但 `clip play` / `speak` 只应出现一次。

### T3 单句时长（票 01）

从日志 `done seconds=` 读，按 4.0–4.3 字/秒推算，容差 ±20%：

| 场景 | 文案示例 | 期望 |
|---|---|---|
| 组开始（带「共 N 组」） | 俯卧撑，第 3 组，共 3 组，12 次 | 3.2–4.6 秒 |
| 组开始（预算丢了「共 N 组」） | 哑铃划船，第 1 组，每侧 12 次 | 2.8–3.8 秒 |
| 休息开始 | 休息，60 秒 | 1.3–2.1 秒 |
| 跨区块休息 | 休息，1 分 30 秒，接下来：平板支撑，40 秒 | 4.5–6.5 秒 |
| 完成 | 完成 9 组，完成率 100% | 2.5–4.0 秒 |

任何一条 **> 5 秒**（跨区块那条 > 6.5 秒）就把整行日志发我。

### T4 倒数不被打断（票 03）

休息最后 3 秒：应完整听到「3」「2」「1」，**然后紧接着是下一组那一句**。

- 旧 bug 有两个，本轮都修了：
  1. 每念一句就 `setActive(false)`，倒数会被掐 → 课程期间整段按住音频会话。
  2. 倒数曾是最高优先级，**「1」还没念完时下一组那一拍会被整句丢掉**（`1 < 2` 直接 return），听感就是「3、2、1……然后静默」。现在倒数与组开始同级，后到者赢。
- 日志判据：`speak(1)` 之后必须还有一条 `speak(俯卧撑…)`，且两条之间是 `cancel` 不是丢失；`deactivate` 只在整节课结束时出现一次。

### T5 来电中断（票 05）

播报进行中，用另一台手机打进来（或长按侧键叫 Siri）。

- 期望：立即停，挂断后**不补念**。
- 日志：`interrupted` 或 `cancel`。
- 失败长相：停不下来，或停了之后把剩下的半句重念一遍。

### T6 拔耳机（票 05）★ 只能真机

连上有线或蓝牙耳机 → 播报中拔掉 / 断开耳机。

- 期望：**立刻停**，绝不能从外放接着念（会议室里最尴尬的就是这个）。
- 日志：`cancel` / `interrupted`（原因是 `.oldDeviceUnavailable`）。

### T7 静音键（AC-24）

拨到静音 → 回 App → 点「试听」。

- 期望：无声。
- 日志：`speak` 和 `done` **都还在** —— 这是对的，说明是系统静音挡的，不是代码拦的。
- 模拟器测不了静音键。

### T8 后台与 VoiceOver（票 05）

1. 训练中播报时按回桌面 → 应立即停（后台不该继续念）。
2. 回 App，设置 → 辅助功能 → 旁白 打开 → 再进训练 → 不应播报（声音让给旁白）。
- 日志：`policy ... foreground=false ...` / `voiceOver=true allows=false`。

### T9 完整一节课（回归）

普通主线（3 个动作 × 3 组）应念这些，顺序一致：

```
开始训练，上肢与核心
俯卧撑，第 1 组，共 3 组，10 次
俯卧撑，第 2 组，共 3 组，10 次
俯卧撑，第 3 组，共 3 组，10 次
哑铃划船，第 1 组，每侧 12 次
哑铃划船，第 2 组，每侧 12 次
哑铃划船，第 3 组，每侧 12 次
平板支撑，第 1 组，40 秒
平板支撑，第 2 组，40 秒
平板支撑，第 3 组，40 秒
完成 9 组，完成率 100%
```

组间休息另念「休息，60 秒」+ 3/2/1 倒数；静力动作（平板支撑）中段会念一句要点。

**注意：哑铃划船没有「共 3 组」不是 bug**——「哑铃划船，第 1 组，共 3 组，每侧 12 次」已经 23 字，超预算，按规则先丢「共 N 组」。

### T10 额外组 + 结束页（回归）

休息页点「再加一组」→ 应念「<动作>，第 4 组，…」；整节课结束念「完成 N 组，完成率 X%，另有 1 组加练」。

### T11 前台不再弹「休息结束」（2026-10-25 修）

在 App 里等一次休息归零，**全程不锁屏、不切后台**。

- 期望：只有触觉 + 播报，**没有横幅、没有系统提示音**。
- 旧行为：`NotificationRouter.willPresent` 对所有通知返回 `[.banner, .sound]`，所以归零那一刻是「横幅 + 提示音 + 触觉 + 播报」四遍，提示音还盖在播报上。
- 反过来要验一次：把 App 切到后台再等归零 → **必须有横幅和提示音**（后台没有 TTS，这条通知就是它存在的理由）。
- 日志：前台 `willPresent rest-end suppressed id=dk.rest.…`；后台不打印（进程被挂起）。

### T11 语音输入顺手点一次

导入页的麦克风（拍下 / 粘贴 / 语音）→ 说一句「我想练背，二十分钟」→ 应正常出确认页。

这一段这次只改了**会话借用**（不再自己 `setActive`），功能本身没动。若出现"第一次点麦克风没反应、第二次才行"，把日志发我——那是会话租约的竞态。

### T12 三档切换与首组要点

1. 把档位改成「精简」，进一节课：**休息开始不念、倒数 3/2/1 不念**，但每组开始照念。
2. 训练中途把档位调成「静音」：正在念的那句应立刻停，之后不再出声。
3. 标准档下，同一个小动作做 3 组：**只有第 1 组**会念动作要点，第 2/3 组只念组数与剂量。

- 期望：以上三条都对。
- 日志：档位切换会打 `policy ... allows=`；精简档下 `speak` 只在组开始时出现。

### T13 音条拼接（阶段 0，只在装了音条的包里有）

这一条不是在验"好听"，是在验**拼接**：

1. 进一节课，听组开始那句「俯卧撑，第 1 组，共 3 组，12 次」——是像一个人连着说的，还是像四段录音拼起来？
2. 特别听三处：动作名和「第」之间、数字和「组」之间、句尾有没有被切掉半个字。
3. 再听开场那句「开始训练，上肢与核心…」——这句会**回落到系统 TTS**（主题名不在音条库），所以两句的音色会不一样。这是预期，不是 bug。

- 对照：`DK_VOICE_CLIPS=0` 强制走系统 TTS，可以 A/B。
- 日志：`clip play segments=4 seconds=3.84`（音条）/ `clip fallback`（回落）。
- **判据只有一条：拼接能不能接受。** 不能接受就停掉整条线，不要往下做 CosyVoice2。

## 4. 这一版**没有**的东西

- **还是系统 TTS**，没接 MeloTTS。开源替换是票 06，卡在"要在 iPhone 上量首音延迟和 RTF"，过不了三条门槛就不换（ADR-0007）。
- 动作中只剩两句：中段要点 + 最后 3 秒。「时间到」「加油」已删（后者从来没被打开过，是死代码）。
- 模拟器测不了：静音键、来电、拔耳机、增强音色。

## 5. 出问题怎么给我

Console.app 里选中相关几行复制粘贴即可；或 Action → Save 存一份。三种信息最值钱：

1. `voice pick` 那一行（音色到底选了谁）
2. `speak` 与 `done` 的配对（时长够不够）
3. `policy` 行（没出声时，是策略拦的还是引擎没响）
