# 02: 端口重画（防腐层的真正形状）

**What to build:** 把「一个会说话的喇叭」换成「一句可取消、有身份、可能失败的话」。

**Blocked by:** 无（口径见 ADR-0007）

**Status:** done（2026-10-25）

## 为什么

现有 `SpeechAnnouncing` 只有 `isSpeaking / speak(String) / stop()`。换成神经引擎会漏五样：

| 缺什么 | 后果 |
|---|---|
| 句柄 id | 异步 `finished` 事件对不上是哪一句 |
| 事件 | 只能轮询 `isSpeaking`，而合成期间它是 `false`（实测 `speak()` 返回瞬间恒为 false）→ 抢占失效 |
| 可用性 | 模型缺失 / 加载失败无处上报，`try?` 全吞 |
| 音色档案 | 引擎、音色、语速写死在适配器；Core 无法按引擎算预算 |
| 线程模型 | 同步 `speak` 装不下「后台推理 + 音频队列播放」 |

## 改动

- [ ] `DongKeCore/Ports/SpeechRendering.swift`：
  - `SpeechRequest { id, text, priority, expiresAt }`
  - `SpeechPriority { aside < instruction < countdown }`
  - `SpeechOutputEvent { started(id), finished(id, seconds), cancelled(id, reason), failed(id, reason) }`
  - `SpeechAvailability { ready / needsDownload(bytes) / unsupported }`
  - `SpeechProfile { engineId, voiceName, charactersPerSecond }`
  - `protocol SpeechRendering { availability, profile, prepare(), render(_:on:), cancel() }`
- [ ] `SpeechCueCoordinator` 改成按优先级 + deadline 决策，删 `isSpeaking` 轮询：
  - 同优先级：新句替换旧句；
  - 高优先级：立刻 `cancel()` 再播；
  - 低优先级：高优先级在播时直接丢；
  - `expiresAt` 已过：丢。
- [ ] `DongKe/Services/SystemSpeechRenderer.swift`：`AVSpeechSynthesizer` + delegate → 事件；`.ambient` 不变。
- [ ] 删 `SpeechAnnouncing`、`SystemSpeechAnnouncer`。

## 验收

- 假 renderer 单测 4 条：同优先级替换 / 高优先级抢占 / 低优先级丢弃 / 过期丢弃。
- 单测：`finished` 事件带回原 `id`（神经引擎乱序返回也不会串句）。
- 真机：连点「完成本组」三次，只听到最后一句，且不叠加。
