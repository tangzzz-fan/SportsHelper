# 04: 音色与试听

**What to build:** 先把手上的好音色用起来，再谈换引擎。

**Blocked by:** 02

**Status:** done（2026-10-25）

## 现状

`SystemSpeechAnnouncer` 写死 `AVSpeechSynthesisVoice(language: "zh-CN")`，只按语言取，**不看质量档**。本机实测该调用返回 `Tingting`，`quality = 1`（compact）；同一台机器上装着 `com.apple.ttsbundle.gryphon-neural_Linfei_zh-CN_premium`（设置里显示「声音2」），代码从未用过它。

这就是「僵硬」的第一来源，而且换引擎的成本是它的几百倍。

## 改动

- [ ] `pickVoice()`：`AVSpeechSynthesisVoice.speechVoices()` 里筛 `language == "zh-CN"`，取 `quality` 最高；同档取用户上次选的（`dk.voice.id`）。
- [ ] `SpeechProfile.voiceName` 上报给 Core，设置页显示当前音色名与档位（增强 / 默认）。
- [ ] 设置页「语音提示」卡片加「试听」：念一句固定文案（`开始训练，上肢与核心，3 个动作，共 9 组`），不写 UserDefaults。
- [ ] 只有 compact 时，卡片下补一行：「系统设置 → 辅助功能 → 朗读内容 → 声音 里可以下载更自然的中文语音。」——不跳转（iOS 无深链），只说明。
- [ ] 语速从写死 0.5 改为 profile 字段，默认 0.5；试听与实战同一条路径。

## 验收

- 真机上设置页显示的音色名与「设置 → 辅助功能 → 朗读内容」里的一致。
- 试听能听见，关掉开关后试听按钮禁用。
- 改变系统默认音色后，App 重启能跟着换（不缓存 identifier 的优先级高于质量档）。

## 不做

- 不做音色商店、不做多音色切换 UI（等 `06` 的引擎位）。
- 不改 `AVSpeechUtterance.rate` 的默认值——0.5 是系统默认，实测 4.0–4.3 字/秒，符合 ≤3 秒预算。
