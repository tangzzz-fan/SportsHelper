# 05: 中断、路由与 VoiceOver

**What to build:** 来电、拔耳机、打开 VoiceOver 这三件事发生时，别继续自说自话。

**Blocked by:** 02, 03

**Status:** done（2026-10-25）

## 现状

全仓没有 `AVAudioSession.interruptionNotification`，也没有 `routeChangeNotification`。

- 播报中来电：会话被打断，恢复后不会续播（可接受），但没有任何状态收敛。
- 录音中来电：`AVAudioEngine` 停了，`VoiceInputMachine` 仍是 `.listening`，空转到 60 秒超时才报「没听到」。
- 播报中拔耳机：声音外放，安静的办公室里会炸。
- VoiceOver：只在 `scenePhase` 与开关变化时刷新 policy，训练中打开 VoiceOver 不会让路。

## 改动

- [ ] `AudioSessionArbiter` 监听 `interruptionNotification`：`.began` → 取消当前句 / 停止收音，**不自动续播**；`.ended` 只更新状态（`shouldResume` 忽略）。
- [ ] 监听 `routeChangeNotification`：`reason == .oldDeviceUnavailable`（拔耳机）→ 立刻 `cancel()`，不转外放。
- [ ] `VoiceInputMachine` 增加中断入口：`.failed(.interrupted)`，不等到 60 秒。
- [ ] `UIAccessibility.voiceOverStatusDidChangeNotification` → `VoiceService.refreshPolicy()`（播报立刻停）。
- [ ] 失败文案沿用 `VoiceInputFailure.interrupted.message`，不新增文案。

## 验收

- 真机：播报中拔耳机 → 立刻静音，且不从头复述。
- 真机：录音中来电 → 2 秒内显示「录音中断了，再点一次试试」，不是空转到 60 秒。
- 模拟器：辅助功能里打开 VoiceOver → 下一句不再念。
