# 竞品与行业方案：训练时怎么出声

查的是「同类 App 的语音方案」，不是功能列表。结论先说：**行业里只有三条路，没有第四条** —— 把内容固定下来用真人录、接受机器音、或者只发提示音。动刻的处境三条都不完全适用，原因在 §3。

## 1. 五家做法

| App | 内容形态 | 出声方式 | 证据 |
|---|---|---|---|
| **Keep** | 固定课程（视频/动图） | **真人配音演员录音** | 2020 新浪科技报道：配音演员付洁，课程设计师在录音棚**现场示范动作**，让她感受「动作与动作之间的呼吸节奏」 |
| **Nike Training Club** | 固定课程 | 真人 Master Trainer 录音 | 评测：cue 覆盖 form / breathing / tempo / modifications；可选 静音 / 只留教练 / 加音乐 |
| **Peloton** | 直播 + 录播 | 真人教练 | Custom Audio 三档：Original / More Instructor / More Music |
| **Apple Workout Buddy** | 生成式（watchOS 26） | 生成式 TTS，**用 28 位 Fitness+ 教练的声音训练** | CNET 采访 Caldbeck：「这不是录音，没有脚本，每次都不一样」 |
| **GymMane** | 用户自选动作 | 现场合成正弦音（880 / 1318.5 Hz）+ 震动 | 源码 `lib/services/beeper.dart`，一句文字都不念 |
| Strong / Hevy | 用户自选动作 | 自动休息计时器（未见公开的语音播报资料） | — |

### 补充事实

- **Keep 的时间点设计**：开始前留 3 秒准备、倒计时 5 秒提示、过程过半提示、鼓励语。
- **Keep 被批评的点**：「多数训练中的语音提示仅包括动作组数、次数，对动作规范提示很少」，要领靠屏幕文字。
- **Apple 被夸的点**：不像「电话推销员式的机器人教练」。
- **Apple 被骂的点**：① 话痨——心率在目标线上下抖时「每隔几秒」提醒一次，官方必须提供逐项关闭；② 语气与内容失配——念「一英里，爬升 230 英尺」之后接一句「这爬升很温和！」，用力过猛，听起来像讽刺。

## 2. 三条结构性发现

1. **「像人」不是模型问题，是录制语境问题。** Keep 的配音演员是在课程设计师当场示范动作、给出呼吸节奏的情况下录的。同一句「第 3 组，共 3 组」，念表格的语速和组间喘气的语速，是两个东西。这解释了为什么换更贵的 TTS 模型收益有限——模型不知道这句话在什么呼吸状态下被听到。
2. **信息量和「话痨」是同一条线。** Apple 的问题不是音色，是频率（几秒一次）与语气错配；Keep 的问题是信息不足（只报数字）。两边都指向同一条判据：**每句必须回答「我现在该做什么」，同一信息只说一次**。
3. **「话多话少」是可配置项，不是设计选择题。** Peloton 给滑杆，NTC 给三档。动刻现在只有开/关，用户只能在「全听」和「全不听」之间二选一。

## 3. 动刻的位置：为什么不能直接抄

- **固定课程 → 预录整句可行。** 我们的计划每天生成，整句无法预录。
- **记录器 → 只发提示音。** 但我们每条播报都在传达「做什么、多少」，去掉就退回 GymMane。
- **生成式 → 需要自己的语音模型 + 大量录音数据**，闭源，只有苹果这类量级能做。

唯一交点：**封闭词表 + 预录音条拼接**。词表是 43 个动作名 + 数字 0–60 + 单位（次 / 秒 / 分 / 组 / 每侧）+ 连接词，约 117 条、总时长 3 分钟。这是「内容动态生成、声音预录」唯一能同时成立的地方。

## 4. 可以直接借的四件事

1. **倒数只能是 3，不能是 5。** Keep 从 5 开始念，因为它的动作靠屏幕呈现；归零后不需要口播动作名。我们需要，归零后那句「俯卧撑，第 3 组，共 3 组，12 次」要占 4 秒，5 秒倒数会直接撞上。**这是形态差异，不是偷懒。**
2. **首组详细、后续精简。** NTC 的 cue 覆盖 form / breathing / tempo，但不重复。我们已有 `cues` 字段，现在每组中段念一句；可以改成第 1 组念要点、第 2/3 组沉默。
3. **三档而不是开关。** 静音 / 精简（只报组开始）/ 标准（+倒数 +中段要点）。Peloton 与 NTC 都证明用户会自己调，而且调过之后很少再改。
4. **录制语境。** 走音条方案时，录「第 N 组」要按组间呼吸的语速念，不是念表格。这一条决定成败——参考 §2 第 1 点。

## 5. 明确不要抄的

- **不要抄「鼓励语」。** Keep 有「太棒了」，那是课程型产品的陪伴感。动刻的立场是「给出口」，且 `allowsEncouragement` 这条链路从来没被打开过（死代码，已删）。
- **不要抄 Apple 的高频提醒。** 心率每几秒提醒一次就到了扰民边缘，CNET 的评价是「有点太话痨了」。我们一组最多 3 条的硬上限方向是对的，别松。
