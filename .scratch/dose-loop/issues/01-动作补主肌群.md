# 01: 动作补主肌群

**What to build:** 每个动作知道自己主要练哪块肌肉。这是「剂量」的分母，没有它整套回路算不出任何东西。

**Blocked by:** None (can start immediately)

- [ ] `Muscle` 九值 + `chineseName`：股四头 / 腘绳 / 臀 / 小腿 / 胸 / 背 / 肩 / 臂 / 核心
- [ ] `ExerciseEntry.primaryMuscles: Set<Muscle>`，47 条全部填满，不留空
- [ ] 复合动作只记主肌群，不记次要肌群（俯卧撑记胸，不记臂；硬拉记腘绳与臀，不记背）
- [ ] 测试：每条至少一个主肌群；同一动作不超过 3 个（超过就不是「主要」了）
- [ ] 测试：`regressionId` 与 `alternativeId` 指向的动作，主肌群必须与源动作有交集——降阶不能降到另一个部位
- [ ] 动作详情页加一行「主要练：股四头、臀」
- [ ] 同步 `docs/SPEC.md` §6 的动作库描述（新增 `primaryMuscles` 字段）

**边界**：只填字段，不补动作。腘绳与小腿各只有 1 个动作，这两处在补齐前不产出剂量提案（见 spec 的覆盖度闸门），所以字段填不准只会沉默，不会产出错误建议。

**一个容易犯的错**：把拉伸类动作（股四头肌拉伸、胸大肌拉伸）也标上主肌群。它们标，但不参与剂量——用 `purposes` 里是否含 `.strength` 来筛，这一步留到 03。
