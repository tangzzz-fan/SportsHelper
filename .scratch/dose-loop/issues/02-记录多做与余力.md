# 02: 记下「多做」和「还有几次余力」

**What to build:** 训练页能记下超出目标的部分，和这一组离力竭还有多远。这两样是加量规则的唯一输入。

**Blocked by:** None (can start immediately)

- [ ] `SetLog` 加 `rpe: Int?`（1–5），`SetLogEntity` 同步；迁移不破现有记录
- [ ] 完成一组后给两个动作：`多做几个`（+1/+2/+3，写进 `actualValue`）与 `还有几次余力`（1–5，可跳过）
- [ ] 余力只在**当天最后一组**问，前面几组不问
- [ ] 跳过余力不影响任何现有功能，`rpe` 保持 nil
- [ ] 测试：`actualValue` 可以大于 `plannedValue`；降阶仍为一半；跳过为 0
- [ ] 测试：`rpe` 落库与回读；nil 与 0 不是一回事（nil = 没答，0 = 不存在的档位，档位从 1 起）

**边界**：不做「每组都问」。一组一问会把训练变成问卷，而问卷会吃掉依从性——这正是本轮要修的那个问题。

**文案取舍**：「还有几次余力」比「RPE」好，因为用户不知道 RPE 是什么；但比「累不累」准，因为「累」是感受，「还能做几个」是可数的事实。
