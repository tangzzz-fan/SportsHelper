# 09: 停练后先给一节课

**What to build:** 两周没来的人，下次打开看到的不是一份完整计划，是一节能做完的课。

**Blocked by:** 03

- [ ] 停练判定：连续 2 个计划日没有 `SessionRecord`（`漏练` 单日不触发）
- [ ] 下次打开时先出重建提案：动作数减半、组数减半，一次性会话
- [ ] 重建不写进 `revision`——它不是新版本，是一次让步
- [ ] 完成 ≥80% → 下一周回到停练前的 80%，再走正常递进
- [ ] 完成 <80% → 保持半量再来一次，不降级、不劝说
- [ ] 测试：连续 2 日无记录 → 有；1 日 → 无
- [ ] 测试：重建完成后剂量按 80% 恢复，且 `revision` 未变
- [ ] 测试：重建期间 `dose` 提案不出现（不叠加两个提案）

**为什么是减半而不是「降一档」**：停练后最缺的不是能力，是「我能做完」的证据。半量是按「几乎一定能完成」设计的，不是按「刚好有挑战」设计的。自 efficacy 靠完成累积，不靠挑战证明。

**边界**：不做「欢迎回来」、不做「你已 14 天没训练」这类提醒。前者是空话，后者是责备。
