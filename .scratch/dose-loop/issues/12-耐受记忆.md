# 12: 耐受记忆

**What to build:** 记住这个人加完量之后能撑几次，用它调下一次的幅度。这是个体化的第二层，也是「越来越懂」唯一能被证明的地方。

**Blocked by:** 04

- [ ] 加量被采纳后，记「第几次训练出现降阶或跳过」（`setbackIndex`，1 = 第一次就崩）
- [ ] 连续两次加量都在第 1 次崩 → 下次幅度减半（1.25%）
- [ ] 连续两次加量都撑过第 3 次 → 下次幅度用上限（5%）
- [ ] 其余情况保持默认 2.5%
- [ ] 测试：`setbackIndex` 序列 [1,1] → 减半；[4,3] → 上限；[2,1] → 默认
- [ ] 测试：加量事件 < 2 次时用默认幅度，不猜

**边界**：只回答「这个人加完量能撑几次」。不预测伤病，不建恢复模型，不做「就绪度评分」——那需要心率与睡眠，本产品没有，编一个出来比没有更糟。

**为什么这一票不在前四张里**：它需要「加量被采纳」这个事件先发生两次，所以在时间上晚于 04。但它的**数据结构要提前留**：票 04 落地时就得把「这次是第几次训练」和「那次训练的降阶/跳过」关联起来，否则这一票要回头改数据。

**判据**：这一票做完，「预测误差」这条指标才有第二项来源。只有能力层时，误差只能解释「能做几个」；有了耐受层，才能解释「能撑多久」。
