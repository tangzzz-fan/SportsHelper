# 11: 补腘绳、小腿与臂的动作（后置）

**What to build:** 让这三个肌群各有第二个力量动作，剂量提案才对它们生效。

**Blocked by:** None——**但它不阻塞任何票**。覆盖度闸门让这三处先沉默，所以缺动作只会少三条提案，不会产出错误建议。

- [ ] 腘绳加 1 个不依赖大重量的动作：单腿罗马尼亚硬拉 / 早安式 / 臀桥腿弯举，选一个能自重的
- [ ] 小腿加 1 个：单腿提踵（现有提踵是双腿，单腿能把强度拉开）
- [ ] 臂加 1 个：钻石俯卧撑 / 凳上反屈伸 / 哑铃颈后臂屈伸，选一个能自重的
- [ ] 按扩库三处同步：`ExerciseEntry`（`cues ≥2 / mistakes ≥1 / regressionName` 非空）+ `PrimaryMuscleMap`、`ExerciseAliasResolver.aliases`（≥3 个别名，且自己的名字要能认出自己）、`gen_figures.py` 的 `MAPPING` + `FigureLibraryTests.records`（无素材走 `_generic`）
- [ ] 测试：三个肌群各 ≥2 个可用力量动作后，覆盖度闸门放行

**票 01 落地后的实测**：`MuscleCoverage.uncovered` = 腘绳、小腿、臂。前两个是动作数少，第三个是「复合动作只记主肌群」的直接后果——俯卧撑、划船、推举都不算臂，只剩弯举一个。这条规则没有错（记次要肌群会让臂的剂量永远不够、永远建议加量），但它把补动作的责任推到了这里。

**判据**：这一票做完，腘绳和小腿的剂量提案才开始出现。如果那时候发现这两个肌群从来没进过任何生成的计划，说明问题不在覆盖度，在 `PlanCatalog` 的挑选逻辑——那要另开一票。
