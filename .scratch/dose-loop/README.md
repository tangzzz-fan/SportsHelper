# 剂量回路

把训练记录接回处方：每周看一眼实际做了什么，把改动摆出来，用户点了才生效。

- spec：`docs/specs/2026-10-25-dose-loop.md`
- 原则：ADR-0004「计划只因用户选择而变」、ADR-0003「外来计划不主动提建议」
- 词表：`GLOSSARY.md` 的「剂量」「有效组」「提案」「采纳」「拒绝」

## 票与依赖

```
01 补肌群 ──┐
            ├──> 03 最小闭环 ──┬──> 04 加量三级 ──┬──> 10 三周加一周降
02 记录 ────┘                 │                  └──> 12 耐受记忆
                              ├──> 05 减量五分支 ──> 06 疼优先
                              ├──> 07 拒绝有余波
                              ├──> 08 外来不主动
                              └──> 09 停练重建

11 补腘绳小腿动作（后置，不阻塞任何票）
```

03 是 tracer bullet：只实现一条规则，但把「记录 → 提案 → 采纳 → 新版本」整条路打通。04 之后只往里加规则，不改这层结构。

## 一张票为什么这样切

**01 和 02 必须先做**，因为它们不是本功能的一部分，是它的前提：没有主肌群，「剂量」没有分母；没有「多做」与余力，加量规则没有输入。两张票都能独立验证，也都不依赖任何未定决策。

**06 排在 05 之后**，因为 `safety` 是减量的一个分支，要复用 05 的分支结构，只是加一条优先级。

**08 依赖 03 但不依赖 05/07**：它只决定「提不提」，不决定「提什么」。

**11 被刻意排除在依赖链外**：覆盖度闸门让腘绳和小腿先沉默，所以缺动作不会产出错误建议，只会少两条提案。不阻塞，就不该阻塞。
