**AC-23**：When 用户输入一句描述并点生成，系统必须先展示「我理解为」确认页；确认后才发起 AI 请求，取消则不发请求。

**AC-24**：While 语音播报开启且 App 在前台，When 进入新的一组或休息倒计时归零，系统必须朗读对应文案；系统静音键打开时不得发声。

**和原票面的三处偏差**（查证后改的，别照旧稿执行）：

1. **AC 编号不是 37/38，是 23/24**——SPEC 现有验收只到 AC-22。
2. **PRD 不做补丁**。PRD 功能表的 F11–F18 已被占用（一致性校验 / 动作替换 / 饮食 / Watch…），且冻结基线写明「PRD 只作存档依据」；再追一套编号只会制造第二套真相。
3. **F 编号只在 SPEC 内成立**。SPEC 自己的 F1–F10 与 PRD 的 F0–F18 不是同一套编号；票面写「F11/F12」指的是 SPEC 这套。

**留下的口径**：AC-24 只约束「开启且前台」「静音键不发声」，不规定文案措辞与语速——那些进 07（文案生成器）与 08（引擎）。
