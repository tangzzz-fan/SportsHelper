# 11: 减载周

**What to build:** 每 4 周的第 4 周自动把目标值降到 0.6 倍，计划页标「减载周」；用户可以关，关掉后第 5 周恢复。

**Blocked by:** 02, 03

**状态：** 已落地（2026-11-18）。864 条单测全绿（新增 11 条）；模拟器截图确认计划页页头「减载周」与今日页训练卡提示。

- [x] `DeloadWeek` 纯函数：`weekIndex(on:startedAt:)` 按 7 天一刀切（不是自然周，跨年靠天数差），`(weekIndex - 1) % 4 == 3` 为减载周
- [x] `applied(to:on:enabled:)` 只改 `target.value`：×0.6 后向下取整、最少 1；重量与组数不动；`revision` 不动
- [x] 计划页页头在计划名右侧标「减载周」（accent 色），今日页训练卡的元信息行下加一句说明
- [x] 设置页「减载周」开关，存 `UserDefaults["dk.deload.enabled"]`，默认开
- [x] **偏差**：没有独立的「生成当周目标值」入口，减载在 `AppShell.activePlan` 上算——显示、开练、提醒计划三处天然一致，也不会写回计划
- [x] 关掉后第 5 周恢复：第 5 周本来就不减载，无需额外逻辑；`enabled = false` 时 `applied` 原样返回
- [x] 没有 `createdAt` 的外来计划永远不算第 4 周——不能凭今天猜起始日
- [x] 单测：第 1/2/3 周不减、第 4 周是 0.6 倍、第 5 周恢复、关掉不减、无起始日不动、最少 1、跨年周数、文案三态
