# 07: 训练中换一个

**What to build:** 训练中某个动作做不了（没器械、太疼），用户能换一个同主肌群的动作，只影响这次训练；剂量仍归原肌群，纪录归新动作。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 候选生成纯函数：低阶替代优先，其次「主肌群有交集且器械可用」；排除当前动作；最多 3 个
- [ ] 训练页给「换一个」入口；选中后当前动作替换，已做的组保留
- [ ] `SetLog` 新增 `swappedFromCatalogId: String?`；剂量归原肌群，纪录归新动作
- [ ] 同一动作被换掉两次，交给现有的「换动作」提案，不新增提案类型
- [ ] `swapUsed` 计数 +1
- [ ] 单测：无候选时入口不显示；换掉后剂量归原肌群；同一动作第二次换触发提案
