# 06: 今天只有 N 分钟

**What to build:** 训练日当天，用户能在训练卡上选 10 / 15 / 20 分钟，得到一份压缩版；练完算「练过（短版）」，记录页标出来。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] `SessionCompressor` 纯函数：输入 `PlanDay` + 分钟数，输出压缩后的 `PlanDay`；每个主导肌群保留第一个动作；组数按时间比例削减、最少 1 组；次数与重量不动
- [ ] 今日页训练卡给三档按钮；点了进入短版会话，不改计划、不改 `revision`
- [ ] `SessionEntity` 新增 `kindRaw: String?`（`full` / `short`）；短版会话的 `plannedSets` 用短版组数，`isCompleted` 自然成立
- [ ] 短版里的「没时间」不再进入减量规则，避免把当天的一次性情况当成计划问题
- [ ] 记录页与结束页显示「短版」标记；本周 x/y 照常计入
- [ ] `shortSessionStarted` 计数 +1
- [ ] 单测：1 / 3 / 5 个动作的压缩结果；每个动作 1 组时不削到 0；三种分钟数的组数单调；不改 `revision`
