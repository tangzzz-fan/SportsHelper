# 08: 器械档位与剂量读实际重量

**What to build:** 第一次练负重动作时，App 问一次器械是可调还是固定档；之后加量提案给出买得到的重量；用户自己加重导致的次数下降，不会被记成退步或「太累」。

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] 器械档位模型：可调（步进 2.5 / 5kg）或固定档位列表；存本机，不进账号（没有账号）
- [ ] 第一次遇到 `load.type != .bodyweight` 的动作时问一次；之后不再问，可在设置页改
- [ ] 加量提案的负重档位改成「取下一个可用档位」；没有更重档位时转加次数或加组数
- [ ] `DoseAdjustment` 读 `actualLoad`：用户自己加重、次数下降，不算没完成，不触发「太累」
- [ ] 连续两次用户都自己加重，给一条纠偏提案「把处方改成你实际用的重量」
- [ ] 单测：8kg 步进 2.5 → 提案 10kg；8→10kg 次数 12→9 不产生减量；连续两次自己加重出纠偏提案；没有更重档位时转加次数
