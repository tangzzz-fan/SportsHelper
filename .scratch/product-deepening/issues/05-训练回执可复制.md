# 05: 训练回执可复制

**What to build:** 用户能把最近 N 周的执行结果复制成一段结构化文本，贴给 ChatGPT 或教练；复制前能看到全文并删掉不想外发的行。

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] `TrainingReceipt` 纯函数：输入 `[SetLog]` + `[SessionRecordSummary]` + `WorkoutPlan` + 周数，输出结构化回执（每个动作的计划 / 实际 / 重量 / 降阶 / 跳过原因 / 疼痛 / 破纪录）
- [ ] 文本渲染：每个动作一行，末尾附「请据此修订，并按 schema 输出」+ `PlanSchemaJSON`；不含任何网络调用
- [ ] 入口：结束页与记录页各一个「复制训练回执」；点击先弹预览，可删行，再复制
- [ ] 复制成功 `receiptCopied` +1；打开预览 `receiptViewed` +1
- [ ] 单测：空日志返回空回执而不是崩；只有跳过时如实写；疼痛行单独成段；回执长度上限 4000 字
