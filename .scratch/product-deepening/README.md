# 产品深化：记准 → 解释 → 回流 → 弹性 → 演进

> 方案与口径：[`docs/specs/2026-11-18-product-deepening.md`](../../docs/specs/2026-11-18-product-deepening.md)
> 词表：「剂量」「有效组」「余力」「微剂量」（`GLOSSARY.md`）
> 原则：ADR-0003（外来计划不主动建议）、ADR-0004（计划只因采纳而变）、ADR-0005（只调变量不调目标）、ADR-0007（播报封闭词表）

## 为什么是这五条

§16 让数据可见，但账本本身不准：`SetLog` 只有次数、没有重量，而主画像用的是 5–20kg 可调哑铃。于是「上次 10 个 · 最好 12 个」可能是一个 8kg、一个 10kg。

所以顺序不是并列，是链：

```
B 记准 ──→ D 解释 ──→ A 回流 ──→ C 弹性 ──→ E 演进
   │                      │
   └──── 同一份回执 ───────┘
```

- **B 记准**是地基。数据错了，解释会解释假进步，回流会让 AI 按错的重量改计划。
- **D 解释**与 **A 回流**共用 `TrainingReceipt`：同一份证据，两个出口（人看 / AI 看）。
- **C 弹性**解决当天，比长期演进更急——断更发生在第三周之前。
- **E 演进**只做减载周，完整周期化等计数。

## 口径（已定，2026-11-18）

| 情形 | 口径 |
|---|---|
| 短版算不算练过 | 算；`plannedSets` 存短版组数，`isCompleted` 自然成立；记录页标「短版」 |
| 导入新版本 `revision` | 默认不加；用户勾「这是上一份的新版本」才加 |
| 回执含不含伤病 | 含；复制前预览、可删 |
| 器械档位在哪问 | 第一次遇到负重动作时，不进引导 |
| B 与 D 谁先 | B 先；D1 与 B1 同批 |

## 怎么算成功

| 计数 | 阈值 |
|---|---|
| `receiptCopied / 训练节数` | ≥ 15% |
| `shortSessionStarted / 断更天数` | ≥ 20% |
| `swapUsed / 训练节数` | ≥ 10% |
| `loadRecorded / 负重组数` | ≥ 30% |
| `recordAtWeight` | 每周 ≥ 1 条 |

全部本地算，不上报。

## 不做什么

社交、饮食、AI 教练对话、HealthKit、云同步、e1RM 大图表、跟练分路、Live Activity / Watch。理由见方案 §7。
