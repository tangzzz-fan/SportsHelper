# 02: 大字模式

**What to build:** 设置里一个「大字模式」开关。打开后字号至少放大到系统辅助尺寸，并且单屏要读、要点的东西变少。是同一套内容的另一种呈现，不是另一套内容。

**Blocked by:** None（可以先做）

**Status:** 待开工（2026-10-25 定案，见 ADR 0001）

## 条目

- [ ] 设置页加开关，持久化到 UserDefaults
- [ ] 字号只设**下限**：`max(系统字号, .accessibility2)`。系统已经比 AX2 大时不再压缩
- [ ] `RestSheetView` 去掉 `dynamicTypeSize(...accessibility2)` 封顶，并重排那张 331 高的面板
- [ ] 校对页降密度：一屏 15 个可点 → ≤6（部位选择与安全卡折进第二屏）
- [ ] 命中区补到 44pt：`PressableGlassStyle` 设最小尺寸；引导页加减按钮 `32×32` 改大
- [ ] 清掉 21 处固定 width/height 里会在 AX2 下截断的那批（休息面板、设置分段控件、伤病输入框、完成率圆环）

## 验收

- 系统字号 AX1 时打开开关，实际字号到 AX2；系统已是 AX3 时仍按 AX3，不变小
- AX2 下全站无截断
- 所有可点元素命中区 ≥44pt
- 关掉开关，一切回到与现在完全一致

## 边界

不做：单独配色、单独图标、单独导航。不引入「老人版」分支。
