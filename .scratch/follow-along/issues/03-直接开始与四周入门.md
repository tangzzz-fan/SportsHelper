# 03: 直接开始（零输入入口 + 4 周入门计划）

**What to build:** 今日页空态给一个「直接开始」，用户不填任何东西、不配 Key、不联网，也能拿到一份 4 周入门计划并执行。

**Blocked by:** None

**Status:** 待开工（2026-10-25 定案，见 ADR 0001）

## 条目

- [ ] 内置一套 4 周入门计划：每周 3 次、每次约 15 分钟、全自重、含扶墙/椅子降阶
- [ ] 内容以现有 `WorkoutPlan` 形状存储，走同一条持久化与执行链路——不新开模型
- [ ] 今日页空态加「直接开始」入口
- [ ] 引导最后一屏给一次同样入口
- [ ] 计划里的每个动作必须在库内且有图示

## 验收

- 全新安装 → 引导 → 今日页空态 → 直接开始 → 拿到可执行的计划，全程无网络、无 Key
- 生成结果的每个 `catalogId` 都能在 `ExerciseLibrary` 查到，且 `hasArtwork` 为真
- 第 4 周结束后不自动续期，给「换成自己的一句话」出口

## 边界

不做：按水平分多套（验证阶段不分群）、用户自建课程、按年龄分支。
