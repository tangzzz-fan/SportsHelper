# 04: 补增肌向训练动作

**What to build:** 补齐「想增肌 · 有哑铃」场景下模型必需、但库里没有的标准训练动作。这是库外动作里唯一属于「我们缺东西」的一类。

**Blocked by:** 01

**Status:** done（2026-10-24）

## 要补的动作（实测出现过的 6 个）

| 名字 | 为什么必须补 |
|---|---|
| 哑铃卧推 | 推类只有俯卧撑和肩推，胸没有负荷动作 |
| 哑铃地板卧推 | 没有卧凳时的替代，实测里模型自己降阶了 |
| 哑铃罗马尼亚硬拉 | 后链只有臀桥和超人式，没有髋铰链 |
| 哑铃侧平举 | 中束三角肌没有孤立动作 |
| 哑铃弯举 | 肱二头肌完全没有 |
| 上斜俯卧撑 | **已取消**。项目已有「上斜」限定词机制：它会被归到俯卧撑并打橙标提示核对，建成独立动作反而拆掉这道提示。 |

## 条目

- [ ] 补 6 个，`purposes` 为 `[.strength]`，`equipment` 正确（哑铃 / 徒手）
- [ ] 每个带 `cues` / `mistakes` / `regressionName` / `affectedParts`
- [ ] 上斜俯卧撑要设 `regressionId` 指向跪姿俯卧撑？**不要**——它的负荷比跪姿高、比标准低，是中间档，`regressionId` 语义是「更轻」，指错方向会误导
- [ ] 单测：`equipment == .dumbbell` 的动作 ≥ 10 个
- [ ] 单测：胸 / 背 / 肩 / 手臂 四个部位各至少一个 `[.strength]` 动作（现在胸只有俯卧撑、手臂一个都没有）

## 验收

重新采样「想增肌 · 一对哑铃」场景，库外动作归零。
