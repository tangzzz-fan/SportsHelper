# 02: 补练前动态热身动作

**What to build:** 把实测里模型自己编的 4 个热身动作收进库，让 `warmup` 区块有库内动作可选。

**Blocked by:** 01

**Status:** done（2026-10-24）

## 要补的动作

实测出现过的（4 个）：

| 名字 | 典型剂量 | 要点 |
|---|---|---|
| 臂绕环 / 手臂绕环 | 1x30 秒 | 同物异名，只收一个，名字取「手臂绕环」 |
| 原地踏步 | 1x120 秒 | 低强度升温，膝伤场景唯一可用的热身 |
| 绕臂画圈 | 1x30 秒 | 与臂绕环高度重叠，合并成一个 |

需要补但实测没出（按覆盖场景补足）：

| 名字 | 为什么 |
|---|---|
| 髋绕环 | 下肢日热身，现在只能用开合跳代替 |
| 猫牛式（若 03 未收） | 脊柱热身，同时是灵活性动作 |
| 肩胛绕环 | 肩颈不适场景的开场，现在完全没有 |

## 条目

- [ ] 新增 5–7 个 `purposes` 含 `.warmup` 的动作，每个带 `cues` / `mistakes` / `regressionName` / `affectedParts`
- [ ] 新增动作的 `affectedParts` 必须与 `PlanSafetyChecker` 的语义一致：只标「会不会让这里明显承重」
- [ ] 热身动作的 `isStatic` 全部为 false（动态热身）
- [ ] 单测：`purposes` 含 `.warmup` 的动作 ≥ 8 个（现有 3 + 新增 5），覆盖 肩/髋/膝/踝 四个部位至少各一个

## 验收

重新采样「膝盖旧伤」「肩颈不适」两个场景，`warmup` 区块里不再出现 `custom_` 前缀的动作。
