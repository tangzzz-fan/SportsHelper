# 01: 日名跟着内容走——别在「上肢日」里排三个下肢动作

**What to build:** 用户看到「上肢与核心」，进去发现五分之三是腿。改的不是内容，是**取名资格**：一节课只做标题说的那件事；本组装不下三个动作，就别叫这个名字，按全身排；全身日则必须两组都有活。

**Blocked by:** None（`§13` 的 A/B 都做完了，这一条独立于剂量）

## 缺陷怎么被发现的

2026-10-25 量处方规模时 dump 出来的（纯自重 / 30 分钟 / 3 天）：

```
周二 上肢与核心 | push_up, superman, glute_bridge, wall_sit, calf_raise
```

根因是 `makeTrainingDay` 里那行 `main = 本组主力 + 另一组填充`：上肢池只有两个力量动作，剩下三个名额只能从下肢里拿。**在没有周组数上限时也存在**，与 B 的失败无关。

有哑铃时同一处会反着露出来：

```
周一 下肢力量 | lunge, glute_bridge, calf_raise, dumbbell_rdl, dumbbell_row
```

第五个名额给了哑铃划船——因为 `spread` 走完下肢的四个主导肌群后，先碰到填充候选，第二轮才轮到第二个下肢动作。

## 三条规则与它们各自的理由

| 规则 | 值 | 不这么做会怎样 |
|---|---|---|
| 专项日只排本组 | — | 标题在骗人（本票的起因） |
| 本组不足三个动作就降级 | `minSpecializedItems = 3` | 只剩两个动作的「上肢日」撑不满 30 分钟，且和全身日没区别 |
| 全身日每组保底两个 | `minSlotsPerGroup = 2` | 只做前两条，全身日 = 四个下肢 + 一个俯卧撑，胸 6、背 0 |

**第三条是实测逼出来的，不是想出来的。** 只做前两条时，`spread` 按主导肌群铺开，纯自重的下肢有四个主导肌群、上肢只有两个，名额自然全给腿；有一版甚至整天没有一个上肢动作。

**边界画在三个**：纯自重（`push_up` / `superman`）降级；加卧凳（多一个 `bench_dip`）就恢复上肢日。测试从两侧钉住这个边界，免得哪天有人把阈值改成「凑满五个才叫专项日」。

## 验收

- [x] `PlanGenerator.makeTrainingDay` 去掉跨组填充；空出的名额由组数吸收
- [x] `resolvedFocus`：本组 `spread` 不足三个 ⇒ `.full`
- [x] `groupSeeds`：全身日每组先占两个名额，按各自肌群铺开、按星期轮转
- [x] `PlanDayNamingTests` 六条（含受伤部位仍被尊重）
- [x] 变异验证：去掉降级 ⇒「纯自重不该出现上肢日」红；去掉保底 ⇒「全身日两组都有活」红
- [x] `DoseBudgetTests` 里那条 `.disabled` 的实测数字按新结果更新

## 已知代价

**5 天 × 60 分钟档的臀从 30 涨到 42。** 下肢日的第五个名额原来给了超人式（上肢），现在留在本组里变成第二个臀动作。五天档本来就在「池子填不满五天」的缺口里——这条没变好，只是从标题里搬到了明面上。真治仍是那两条：降组数（选 60 分钟只练 45，得明说）或降频率（提示改成三天）。

## 不做什么

- **不给全身日起第二套名字**（「全身循环 A/B」）。两天内容本来就不同（按星期轮转），加后缀是噪声。
- **不动 `maxItemsPerLeadMuscle`**。下肢日出现「臀桥 + 臀推」是同肌群第二个名额的正常结果，不是串组。
- **不补上肢自重动作**。上一轮已经证明会被 `ExerciseNounTests` 的变式规则挡回，那条规则是对的。
