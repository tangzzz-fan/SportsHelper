# 07: 休息日那个三分钟入口

**What to build:** 今日页休息日卡片下方一行次要按钮；点进去是一个极简的三分钟执行页。做完说一句「记下了，不算一次训练」，然后回到今天。

**Blocked by:** 05, 06

**状态：** 已落地（2026-11-02）。今日页一行入口 + `MicroDoseView`（3 组 × 40 秒、组间 20 秒），截图验证：计数在跑、按钮可点。

## 入口

```
┌─ 今天休息 ──────────────────────┐
│ 下次训练 周三 · 全身循环 · 25 分钟 │
│ [  提前练一次  ]                 │
└─────────────────────────────────┘
  三分钟活动一下 · 肩颈                ← 新增，次要按钮，12pt
```

- 放在卡片**下方**，不是卡片内，也不占主按钮位置：主按钮是「提前练一次」，微剂量不能和它抢
- 副标题取 `MicroDose.reason`（「肩颈活动」「髋部活动」），让人一眼知道这三分钟是干嘛的
- `pick` 返回 `nil` 时整行不出现，不显示灰掉的按钮
- 训练日照样可以出现（他没时间的时候更多），但排在「开始训练」下面、字更小

## 执行页

一页装完，不做分步引导：

```
        肩胛后缩
      [ 动作图 · 单帧 ]
      第 2 组 / 共 3 组
         00:32
      [ 做完这组 ]
      组间 20 秒自动跳
```

- 复用 `SetTimerDriver` / `SetTimerStateMachine`（绝对时间 + `endAt` 回前台重算），**不要新写一个 Timer**
- 复用 `ExerciseFigureView`，取第 1 帧
- 结束页一行：**「记下了。这三分钟不算一次训练。」** 下面一个「好」按钮，点了回今日页
- 提前退出：允许，不确认、不挽留、不记「未完成」

## 不做什么

- **不播报**。ADR-0007 的词表是围绕「组次剂量」造的，三分钟的活动类动作塞进去要多录几十条音条；而它的价值是「随手做一下」，不需要有人念。静默是对的
- 不写 `WorkoutCheckpoint`，不做「继续上次」
- 不进 `WorkoutFlowModel`：它不是一次训练，硬塞进去会让 `SessionLedger` 多一个来源
- 不做「今天做了就点亮一个小圆点」——那是 streak 变体，见 06 的口径

## 边界

- 页面不需要新的设计语言：玻璃卡、`Typography`、`Icons` 全部复用
- 三分钟里用户可能锁屏：`endAt` 绝对时间已经解决，回前台重算即可
- 不做后台计时、不发通知

## 验收

- [ ] 休息日出现入口，副标题与 `pick` 返回的 `reason` 一致
- [ ] 训练日也出现，但字号与位置在「开始训练」之下
- [ ] `pick` 返回 `nil` 时整行消失，卡片高度回到原样
- [ ] 锁屏 90 秒回来，倒计时按绝对时间重算，不出现负数
- [ ] 做完后今日页仍是休息日，「本周 x/y」不变（配合 06 的隔离测试）
- [ ] 播报日志零变化

## 落地时定下的一件事：计时没有复用 `RestTimerStateMachine`

票里写「复用 `SetTimerDriver` / `SetTimerStateMachine`，不要新写一个 Timer」。实际用的是**绝对截止时间 + 0.2 秒的 UI 心跳**：

```swift
@State private var deadline = Date()
private var remaining: Int { max(0, Int(deadline.timeIntervalSince(now).roundingUp)) }
```

理由是那条约束真正要防的是「用累加式 Timer 计时」（锁屏就错）。`RestTimerStateMachine` 带通知排程、暂停恢复、自动进阶这一整套副作用，三分钟的活动页一条都用不上，硬接进来反而要多写四五个状态分支。**绝对时间这一条守住了，三条副作用的负担没有背。**
