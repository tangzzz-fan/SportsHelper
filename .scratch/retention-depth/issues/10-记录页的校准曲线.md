# 10: 记录页那条校准曲线

**What to build:** 记录页加一节：四周的预测误差，配一句话。让 ADR-0005 那句「误差在收窄才叫懂你」第一次可被用户看见。

**Blocked by:** 09

## 展示

```
我的猜测有多准
  2.4  1.9  1.2  0.8        ← 四周，左旧右新
  这周我猜你的次数，平均差 0.8 个
  （四周前是 2.4 个）
```

- 四根柱，最后一根是本周；不做折线（四个点画折线是装饰，不是信息）
- 数字单位是「个」或「秒」，按本周参与计算的单位取多数；混了两种单位就分两行，不合并
- 下降用中性叙述，不庆祝：**「差 0.8 个」**，不是 **「准确率 92%」**——百分比会让人以为是考试，而这个数说的是「我了解你的程度」

## 什么时候不出现

- 参与计算的组数 < 12（大约两节课）：样本太少，一句话都说明不了
- 只有一周数据：没有「收窄」，只有绝对值，那是在夸自己
- 全周都是降阶 / 跳过：分母为 0

**不出现时不留空位**，与 04 的周报同一个原则：0 不是消息。

## 文案口径

| 情形 | 文案 |
|---|---|
| 误差变小 | 这周我猜你的次数，平均差 0.8 个 |
| 误差变大 | 这周猜得比上周差一点，差 1.4 个 |
| 误差不变 | 这周和上周差不多，都在 1 个上下 |

**不许说「AI 越来越懂你了」。** 那是结论，用户自己会得；说出来就成了话术。ADR-0005 要的是一个可证伪的判据，不是一句自我表扬。

## 边界

- 不做「预测 vs 计划」的对比图：那是处方质量，不是校准
- 不做分动作的误差榜：一个动作两周才练一次，样本不够
- 不改记录页现有的四块（本周有效组 / 肌群横条 / 四周柱 / 跳过原因），这一节加在最下方

## 验收

- [ ] 四周数据齐全时显示四根柱，最后一根是本周
- [ ] 组数 < 12 时整节不出现，页面高度回到原样
- [ ] 只有一周数据时不出现
- [ ] 单位混用时分两行，不把「个」和「秒」平均成一个数
- [ ] 文案里不出现百分比、不出现「越来越懂你」
- [ ] 与 04 的「这周 N 个动作破了纪录」同时存在时不抢位置（04 在上，10 在最下）
