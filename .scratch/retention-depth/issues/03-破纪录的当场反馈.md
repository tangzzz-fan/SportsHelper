# 03: 破纪录的那一秒，说一句

**What to build:** 用户点「完成本组」时，如果这组的实际值超过了**这一组之前**的历史最好，当场给一句话加一次触觉。让「变强」这件事发生在他还喘着的那三秒，而不是等周报。

**Blocked by:** 01, 02

## 判定

```swift
let before = PersonalRecords.build(logs: didLogs, before: now)
if let best = before[key]?.best, actual > best { 破纪录 }
```

三条必须同时成立：

1. `status == .done`（降阶不算，理由见 01）
2. `actual > best`，**严格大于**——平纪录不庆祝，否则第二周每次都是「破纪录」，这个词就贬值了
3. `before` 传本组完成时间，**不含本组**。漏了这条，第一组 10 个就立刻超过「历史最好 10」，第二组 11 个再超它自己，一节课炸三次

## 反馈形态

- 一行字，接在「这组完成」下面：**「深蹲最高纪录 13 个」**（静态动作：**「平板支撑最长 48 秒」**）
- 一次触觉：新增 `Haptics.recordBroken()`，用 `UINotificationFeedbackGenerator().notificationOccurred(.success)`，**不配音效**。现有三档是 `restFinished` / `setLogged` / `setTimeUp`，都带 `AudioServicesPlaySystemSound`，破纪录不该和它们混用——组间已经很吵了
- **不弹窗、不弹 toast、不播报**。组间那三秒屏幕上是休息倒计时，任何遮住倒计时的东西都是减分
- 同一节课同一动作**只庆祝一次**：循环组里连炸三次会把这句话变成噪音

## 文案口径

| 动作 | 文案 |
|---|---|
| 计次 | 深蹲最高纪录 13 个 |
| 静态 | 平板支撑最长 48 秒 |
| 首次那条动作（无历史） | **不庆祝**。没有「之前」，就没有「破」 |

不用「太棒了」「厉害」这类评价词——它评价的是人，不是事实。事实本身已经够响：他上次做 12 个，这次 13 个。

## 边界

- 不写新的存储：纪录由 01 现算，不落「破了纪录」这张表
- 不改完成率、不改剂量、不产生提案（破纪录不是加量证据；加量证据是 `clearedEverySet` 那条，见 BACKLOG §15）
- 不做动画、不做彩带、不做音效。**新增一个音效就要多一条音条资产，而 `VoiceClips` 那条链路是封闭词表维护的**

## 验收

- [ ] 第一组就超过历史最好：出一句；同节课后续再超：不再出
- [ ] 平纪录：不出
- [ ] 低于纪录：不出，也不说「还差 1 个」（那是催练）
- [ ] 降阶组超过历史最好：不出（降阶的目标已经被压低，这个「超过」是假的）
- [ ] 首次练某个动作：不出
- [ ] 触觉只响一次，不是每帧
- [ ] 播报与播报日志零变化
