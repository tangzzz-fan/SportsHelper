# 05: 微剂量选哪个动作

**What to build:** 一个纯函数，给定档案（器械 / 不适部位）、本周计划、今天，返回**一个**动作和它的三分钟处方。选不出来就返回 `nil`，不要凑一个。

**Blocked by:** None

**状态：** 已落地（2026-11-02）。`DongKeCore/Scheduling/MicroDose.swift`，7 条测试；模拟器截图：档案标了「肩颈」时选到`颈部等长`，副标题「肩颈活动」。

## 为什么要选，而不是让用户挑

微剂量只在一个时刻被用到：**他今天真的不想练**。那一刻让他从 58 个动作里挑一个，等于又给他一道题。选择题会把「三分钟」变成「又得想」。

所以它是系统给的，不是用户挑的——但这跟「计划只因用户选择而变」不冲突：微剂量不改计划，它是一次性地活动一下（ADR-0004 管的是处方）。

## 候选与排序

```
候选 = ExerciseLibrary.all
        .filter { !$0.purposes.contains(.strength) }     // 舒缓 / 活动度 / 热身，不排力量动作
        .filter { $0.affectedParts.isDisjoint(with: 不适部位) }
        .filter { $0.equipment 在档案可用的范围内 }
```

排序三条，从前往后：

1. **命中不适部位**的优先：`relievedParts` 与档案里 `injuries` 对应的部位有交集 → 排最前。久坐的人档案里多半有肩颈，这条会让「三分钟」正好对上他的痛处
2. **不需要器械**的优先（`equipment == .bodyweight`）：他今天不想练，多半也没心情找弹力带
3. **本周还没排过**的优先；都排过就按 `id` 字典序兜底（**不要随机**：同一天两次打开必须是同一个动作，否则用户会觉得这功能在乱跳）

命中后取第一个，`seed = 周起点 + 周几` 只用来在同档候选里错开，不用来打乱档位。

## 处方

固定形状，不给参数：

```
1 个动作 × 3 组 × 每组 40 秒 · 组间 20 秒 = 160 秒
```

- **目标一律 `durationSec`**。微剂量的目的不是计数，是让身体动一下；三分钟里还让他数次数，是把简单事变复杂
- 160 秒 ≤ 180 秒，留 20 秒给开始与结束的两次点击
- 不设休息日专属动作：这个动作本身就该是「每天做也不亏」的强度

```swift
public struct MicroDose: Equatable, Sendable {
    public var catalogId: String
    public var name: String
    public var sets: Int          // 3
    public var seconds: Int       // 40
    public var restSec: Int       // 20
    public var totalSeconds: Int  // 160
    public var reason: String     // 「肩颈活动」，给卡片副标题用
}

public enum MicroDosePlanner {
    public static func pick(
        profile: UserProfile,
        plan: WorkoutPlan?,
        on date: Date,
        calendar: Calendar
    ) -> MicroDose?
}
```

## 边界

- **不进 `PlanGenerator`**，不改计划的任何字段，不改今日页的 `estimatedMinutes`
- 不因为「连续几天没练」而升级成完整训练——那是催练，ADR-0003 的立场
- 不做多个候选让用户换（「换一个」是下一票的事，先验证有没有人用）
- 库里 `purposes` 全是 `.strength` 时返回 `nil`：宁可没有这个入口，也不要给一个力量动作然后说「三分钟」

## 验收

- [ ] 纯函数，只读档案与计划，不碰 SwiftData
- [ ] 同一天调两次，返回同一个 `catalogId`
- [ ] 档案里标了肩颈不适时，优先返回 `relievedParts` 含肩颈的动作
- [ ] 档案只有自重器械时，不返回需要弹力带的动作
- [ ] 返回的动作 `purposes` 一定不含 `.strength`
- [ ] 返回的动作 `affectedParts` 与不适部位无交集
- [ ] `totalSeconds == 160`，且 ≤180
