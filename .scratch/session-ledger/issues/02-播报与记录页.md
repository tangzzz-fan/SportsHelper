# 02: 播报与记录页补上额外组

**What to build:** 加组能落库之后，把「额外 N 组」补到三个用户看得到的地方。**不改任何口径**，只把已经算出来的数说出来。

**Blocked by:** 01（已落）

**状态（2026-10-25）：已落地。** 结束页、记录页 footnote、播报三处都补了额外组；播报新增 `finishedWithExtras`，`extraSets == 0` 时仍走原 `.finished`，既有文案逐字不变。

## 三处

| 位置 | 文案 | 条件 |
|---|---|---|
| 结束页环形图下方 | 「另有 2 组额外加练，计剂量，不计完成率。」 | `recap.extraSets > 0` |
| 记录页 footnote | 「完成 12 组 · 额外 2 组 · 跳过 1 组」 | `report.extraSets > 0` |
| 播报结束语 | 「完成 12 组，完成率 100%。另有 2 组加练。」 | `extraSets > 0` |

**完成率那个百分比不因额外组变化。** 文案必须把「计剂量，不计完成率」说透，否则用户会以为 App 把他的加练吞了。

## 播报怎么接

`WorkoutAnnouncement.finished(completedSets:plannedSets:)` 增加第三个参数 `extraSets: Int = 0`，默认 0，既有测试与调用方不改。`WorkoutAnnouncementBuilder.finished(completedSets:extraSets:)` 透传；`WorkoutVoiceSession.finished` 增加参数；`WorkoutSession+State.finish` 从账本取 `extraSets`。

单测要锁：`extraSets == 0` 时文案与现在逐字一致（不能因为加参数多出半句）。

## 验收

- [ ] 没有额外组时，三个位置的文案与现在**逐字**一致
- [ ] 有额外组时，三处都出现「额外 / 另有」，完成率百分比不变
- [ ] 播报单测覆盖 0 / 1 / 3 组
- [ ] 记录页 footnote 顺序固定：完成 → 额外 → 跳过
