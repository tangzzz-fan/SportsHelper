## 一句话生成与语音播报：先核查，再拆票（12:00）

起因：用户问「能不能描述一句就生成计划」「有没有语音播报」，没有则走 ask-matt 咨询后拆分。

**核查结论（未改代码）**

- **一句话生成是半成品**：`AIPlanClient.generatePlan(profile:extraNote:)` 早就支持 `extraNote`，三级降级 / 64KB / `PlanValidator` 都在；但 `AIGenerateCard` 调它时写死 `extraNote: ""`，用户没有输入句子的地方。`AIPromptBuilder.userBrief` 也已把 `extraNote` 渲染成「补充要求」。
- **语音播报完全没有**：全仓无 `AVSpeechSynthesizer` / `AVAudioSession`。休息归零只有 `Haptics.restFinished()` = 系统音 `AudioServicesPlaySystemSound(1057)` + 触觉，AC-12 的「声音」靠它满足，不是 TTS。
- **顺带两处**：`AIPlanInterpreter.interpret(text)` 没传 `memory` / `exercises`，AI 生成会无视别名记忆与「我的动作」；`AIPlanClient` 在 App target，网络层无测试，401/429/坏 JSON/降级全靠手测。

**ask-matt 路由**：多会话构建 → grill 澄清 → to-spec → to-tickets。项目已有 FROZEN + SPEC 与 `.scratch/<feature>/issues/` 本地看板，跳过重写 spec，直接落票；文档补丁单独一票。

**四个产品决策（用户选定）**

1. 输入：文字 + 语音（Speech 转写回填）
2. 冲突：生成前先「我理解为…」；本次覆盖档案，**伤病只增不减**，不写回档案
3. 播报：关键节点 + 休息最后 3 秒倒数
4. 默认关、仅前台，不申请后台音频

**看板**：`.scratch/brief-and-voice/`，10 票。前沿 = 01 文档补丁 / 02 `PlanBrief` 解析 / 05 AI 传输层可测化 / 07 播报文案。关键依赖：03 确认页 ← 02；06 语音输入 ← 03；04 接线 ← 02,03,05；09 挂流程 ← 07,08；10 真机验收 ← 06,09。

**刻意不做**：语音指令控制、锁屏 / 后台播报、多语言多音色、把一句话写回档案、云端 TTS。

**留给实现的两处坑**：① 播报用 `.ambient` 尊重静音键，代价是不 duck 音乐，音量大时听不清；② 中文离线识别并非所有机型可用，在线识别与「数据只存本机」有张力，授权前必须说清。

## TTS 选型（12:20）

结论：MVP 用系统 `AVSpeechSynthesizer`，不引第三方。

- 排除 Piper / Kokoro：音素化依赖 eSpeak-ng（GPL-3.0），与闭源 App Store 分发冲突；Kokoro 权重虽是 Apache-2.0，G2P 仍是毒点。
- 备选 `sherpa-onnx`（Apache-2.0，iOS 有 Swift 示例，可同时做 ASR + TTS，中文 VITS / ZipVoice）：只有需要品牌音色或离线 ASR 时才上，代价是 xcframework + 60–120MB 模型，且要改 FROZEN「零第三方依赖」。
- MeloTTS / CosyVoice 太重；Edge TTS 需联网，违背离线承诺。
- 结论写进 `.scratch/brief-and-voice/issues/08-speech-announcer.md` 的「选型」节。

## 02 PlanBrief（12:40–12:45）

- `PlanBrief`（全 optional 覆盖）+ `resolved(against:)`：没说的回落档案，伤病只增不减；`maxExercises = sessionMinutes/5`、`maxSets = sessionMinutes/2`。
- `PlanBriefParser`：星期 / 频率 / 时长 / 器械 / 目标 / 重点 / 避开；「隔天」不硬换算，写进 `unparsed`。
- 两个必须记住的歧义：① `每周三天`、`每周三练` 里的“周三”不是星期三，先把 `每/一 + 周 + 单个数字 + 天/次/练` 从星期文本剔掉；`周一三五练` 是一串星期，不能剔。② `天天练` 会被“两个天=周日”误吃，解析星期前先剔 `每天/天天`。
- 显式星期存在时不再猜天数，避免 `每周一三五练` 被读成“五练”。
- `TextNormalization` 增补 `天`、`小时` 单位与 `週/練/時/鐘/個/兩/傷`。
- 测试 335 → 371 全绿（36 条新用例）。
