## T06 播放 + T07 玻璃（22:52-22:56）

- `FigurePlayback`（Core，纯逻辑）：`canPlay` 要求 `motion == .loop && frameCount > 1`；toggle 关闭时回首帧；`advance` 在暂停/静力下是 no-op。`FigurePlaybackCoordinator` 单独表达「同屏只播 1 个」。7 条测试，测试 64 → 71。
- UI 层：三帧**叠放**用 opacity 做 120ms 交叉淡入，`Timer.publish(every:0.8)` 推进；播放态由 `@MainActor @Observable FigurePlaybackStore.shared` 仲裁，另一个开始播放时旧的自己 `stop()`。
- **玻璃的关键教训**：`.glassEffect` 加在**容器**上会把子内容一起做 vibrancy，卡片里的线条插画直接被压成灰色；正确姿势是 `content.background { shape.fill(.clear).glassEffect(...) }`——玻璃只是背景层，内容画在玻璃之上。第一版截图就是这个错。
- 第二个教训：`glassEffect(.regular.tint(...))` 得到的按钮是「浅色底 + tint 文字」，跟设计的实心深青绿按钮差很远 ⇒ 主按钮改回实心 tint + 顶部高光描边，玻璃只用于卡片/条/sheet。
- `GlassSurface` 双路径：`#available(iOS 26.0, *)` 走原生，否则 `ultraThinMaterial` + 四件套（内高光 55%、外描边 25%、顶亮底暗 1.5pt、120° 镜面高光）。页面代码零版本判断。
